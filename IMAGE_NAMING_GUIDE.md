# Cake image naming guide

Use descriptive, lowercase names separated by hyphens. Include the cake type, a useful design detail, and `wellington` only when it is genuinely relevant.

Examples:

- `eggless-bluey-birthday-cake-wellington-01.webp`
- `vegan-chocolate-cupcakes-wellington-01.webp`
- `gluten-free-rasmalai-anniversary-cake-01.webp`
- `eggless-baby-shower-teddy-bear-cake-01.webp`

Rules:

- Use `.webp` for new web images where possible.
- Avoid dates, `IMG`, `WA`, spaces, brackets, and duplicate names.
- Keep a unique number only for multiple photos of the same cake.
- Update the image `src`, `alt`, page title/caption, and any image list together when renaming.
- Write alt text for the photo, not a list of keywords. Example: `Eggless Bluey birthday cake with fondant stars made in Wellington`.

Rename gradually, category by category, so links and gallery scripts remain intact.
